KazCode

A 15-opcode esolang built from non-empty ordered selections of K, a, z

 

    Compiles plain text into a KazCode program that prints it. Uses only the 8 core Brainfuck-equivalent opcodes, with multiplication loops for compactness.

    Executes a KazCode program and shows the text it produces. Optional stdin for programs that read input.

     
    #TokenBFOperation
    1K>Move tape pointer right
    2a<Move tape pointer left
    3z+Increment current cell (mod 256)
    4Ka-Decrement current cell (mod 256)
    5Kz.Output current cell as a byte
    6aK,Read a byte into current cell (0 at EOF)
    7az[Jump past matching zK if cell == 0
    8zK]Jump back to matching az if cell != 0
    9za—PUSH: push current cell onto data stack
    10Kaz—POP: pop data stack into current cell
    11Kza—DUP: duplicate top of data stack
    12aKz—SWAP: swap top two data-stack values
    13azK—DROP: discard top of data stack
    14zKa—CALL: push return PC, jump to cell % len
    15zaK—RET: pop call stack into PC, or halt if empty

    Lenient mode

    Strict mode throws on any malformed program. Lenient mode recovers silently instead:

    • Invalid tokens are skipped.
    • Unmatched az jumps past the end (runs once); unmatched zK is ignored.
    • Data-stack underflow reads as 0 — POP sets the cell to 0, DUP pushes 0, SWAP fills the gap with 0, DROP does nothing.
    • zaK RET on an empty call stack halts.

    The step limit still applies, and every recovery is listed under the Playground output as a warning.
